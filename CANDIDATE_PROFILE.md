## 3. Почему я — 4 причины именно я

1. **Без ручной сверки.** Один `docker compose up` → каталог готов за секунды. Пример: **170 позиций и 4844 изображения за 1.8 сек** вместо 2 недель (пример из авто, тот же подход для товаров/недвижимости/запчастей).
2. **Детерминизм.** Повторный запуск = бит-в-бит тот же файл. Импортёр не ругается.
3. **Docker-репродуцируемость.** Любой человек запускает и получает тот же результат. Нет “у меня работает”.
4. **Объясняю просто + показываю.** Для бизнеса — скринкаст и NDA-safe без кода. Для технарей — репо, `656+` / `12` тестов.

## 6. Проекты — что делал и что получите вы (NDA-safe, простыми словами, общо)

**Паттерн для всех:** Проблема бизнеса → Что сделал → Под капотом → Что получите вы.

### MorCars CRM — CRM с каталогом и бронями (пример: автопрокат 170, но подход общий)
**Проблема:** Каталог разбросан, дубли, тарифы вручную, брони без логики.
**Что сделал:** Связал `парсер → CRM`: `172` позиции (`sitemap+union`), дедуп `243→172`, полный `XLSX` тарифов (`172/1638`), калькулятор `92/100`, `offer-builder` (`greeting/Location`), `AddressField`, фильтр `CRM+public`. `Docker`, `wipe+reimport`.
**Под капотом:** Python 3.11, FastAPI, MySQL, Docker.
**Что получите вы:** Тот же подход для вашего каталога — товаров, квартир, услуг — чистый каталог, цены из таблицы, брони с логикой, импорт без правки. *NDA-safe скринкаст.*

### JustCars Exporter — детерминированный экспорт (паттерн для любого импортёра)
**Проблема:** Перенос `100-500` карточек в импортёр — ошибки заголовков/чисел.
**Решение:** Один пайплайн: `24/24`, нормализация, детерминированные фото, `1.8s`, `no diff`.
**Что получите вы:** Файл, который принимает ваш `1С / Rozetka / HubSpot / custom`.

### LedStil — флагман, самый большой (2500+ товаров, 500+ категорий)
**Проблема:** Тысячи товаров, категории, атрибуты в хаосе, админка без защит, тормозит.
**Решение:** PHP без фреймворка, генерация `public/products/{ua,ru}`, `.htaccess`, аудит 5 Critical (анонимные записи, CSRF, traversal, секреты), сортировка атрибутов per категории + drag&drop + autosave 30s.
**Что получите вы:** Магазин, который не падает и где порядок наводится перетаскиванием. *NDA-safe скринкаст.*

### Ingul — витрина
**Проблема:** Клиенту нужно листать каталог на телефоне быстро, без CMS.
**Решение:** Статичный каталог: свайп, лайтбокс, `12/14/18` фото, `Pages`.
**Что получите вы:** Быструю витрину для любого каталога.

### AgendHub — платформа управления агентами (fork OpenCode, NDA)
**Проблема:** Контроль над агентами/подписками/провайдерами.
**Что сделал:** Форк `OpenCode` → `runtime/ + control-plane/`, `Vault 193→338 nodes`, `Memory Graph`.
**Что получите вы:** Понимаете — беру большой чужой код и делаю продукт. Детали под NDA.

### DocumentAnalyzer — поиск по документам офлайн
**Проблема:** `PDF/DOCX/сканы` не ищутся.
**Решение:** `PySide6 + SQLite FTS`, чанки, `OCR`, многопоток.
**Что получите вы:** Поиск `<1 сек`, локально.

### Aivora / XrayBot / Payment Bots — Telegram + платежи (санитизировано)
**Проблема:** Сигналы/воронки/оплаты вручную, боты падают.
**Решение:** `30m 0.60`, `Funnel 8` + `Achievements 24`, `HD TON/USDT`, `409`.
**Что получите вы:** Бот не дублирует списания, ведёт по воронке. Детали — NDA.
