# Illia Druzhenko

Личная страница с рассказом обо мне, подборкой автоматизаций и контактами.

Сайт размещён на [GitHub Pages](https://illmxnn.github.io/) и публикуется из корня ветки `main`. Сборка не нужна. Для локального просмотра запустите `python -m http.server 8000` и откройте `http://localhost:8000`.

Текст и плейсхолдеры находятся в `index.html`. Оформление — в `style.css`. `site.js` отвечает за переключение темы, индикатор прокрутки и открытие автоматизации по прямой ссылке.
