# Illia Druzenko

Личная страница с рассказом обо мне, подборкой автоматизаций и контактами на русском, украинском и английском.

Сайт размещён на [GitHub Pages](https://illmxnn.github.io/) и публикуется из корня ветки `main`. Сборка не нужна. Для локального просмотра запустите `python -m http.server 8000` и откройте `http://localhost:8000`.

Тексты находятся в `_source/locales.mjs`, общая разметка — в `_source/template.html`. После правок запустите `node _source/build.mjs`, чтобы обновить `index.html`, `uk/index.html` и `en/index.html`. GitHub Pages публикует готовые HTML-файлы. Оформление — в `style.css`, интерактивность — в `site.js`.

Визуальный референс и основа для анимаций — [Glitch](https://github.com/iamovi/glitch) от Ovi ren. Условия лицензии приведены в `THIRD_PARTY_NOTICES.txt`.
